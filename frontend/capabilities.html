Implemented in this build

What you can actually use right now.

Every capability below is live in the prototype. Items that run on deterministic demo providers (clearly marked) sit behind the same interface a production provider would use — the workflow, permissions and records around them are real.

Implemented

AI-assisted intake

Adaptive, source-linked structured interviews behind a clean provider interface. The language model itself is a deterministic demo provider.

Implemented

Voice & read-aloud

Browser speech recognition for answers and speech synthesis for questions, in all four supported languages. Quality depends on the browser’s speech engine.

Implemented

Adaptive interview

Six complaint pathways plus a returning-visit mode that asks only what may have changed, carrying forward previously verified information.

Implemented

Longitudinal history

Every visit, versioned structured history, AYUSH record and timeline event, stored per patient with stable PCI identifiers.

Implemented

Documents & OCR

Upload, store, extract and review prescriptions, labs and imaging. Low-confidence extractions are flagged for human review. The extractor is a deterministic demo provider.

Implemented

Structured clinical context

Every datum is labelled — patient-reported, document-extracted, AI-organized or doctor-verified. Missing stays “not provided”.

Implemented

Doctor verification

Versioned summaries move AI_DRAFT → PATIENT_CONFIRMED → DOCTOR_VERIFIED, with doctor identity, timestamp and visit persisted on verification.

Implemented

Emergency workflow

Fixed red-flag rules and patient-triggered alerts with acknowledge/resolve states, real-time delivery and audit entries.

Implemented

Audit trail

Logins, visit creation, uploads, summary generation, confirmations, doctor access, verification and emergency state changes are all recorded.

Mock readiness

FHIR / ABDM adapters

Resource-shaped output and a clean adapter boundary so a FHIR server or ABHA linkage can be connected without touching the clinical workflow.
