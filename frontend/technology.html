Technology & readiness

Built as a clinical system, not a demo screen.

Preclinic IQ AI is a working prototype with real roles, records, workflows and audit. AI, OCR and speech run on deterministic providers behind clean interfaces — the clinical workflow around them is production-shaped.

Patient → Voice → AI → Documents → Context → Doctor

Voice and text become structured, source-linked history. Documents are OCR'd with confidence; low-confidence flagged for review. Context is versioned; verification is a persisted state change.

Deterministic safety

Red-flag rules run in backend Python, not in a chatbot. Emergency alerts are acknowledged/resolved with audit. No automatic ambulance or 112 integration.

Role-based access at the API

Patients read only own records; doctors access institute patients; admin sees system. Direct document URLs enforce same checks — 403 on cross-patient access, no filesystem paths exposed.

Four languages, honestly

English, Hindi, Tamil, Bengali. Interview text, buttons and voice recognition follow selected language; transcript stays in spoken language, never silently translated.

AYUSH as first-class record

Prakriti, vikriti, ahara, vihara, nidana — optional, with Skip / I don't know / Not sure / None. Skipped stays unknown, never auto-inferred.

Interoperability ready

Structured output shaped for FHIR/ABDM, clean provider boundaries for AI/OCR/ASR, audit trail of every state change, file storage by pointer not embedded.

What is demonstrable today

Login as two different patients and try to open each other's documents (403), open a doctor route as patient (403), watch timeline fill as visit moves intake → AI summary → patient confirm → doctor verify, upload PDF/JPG and open it in doctor viewer with real bytes.
